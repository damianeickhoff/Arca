Stuck, found a bug, or have an idea? Arca is developed in the open on GitHub.

## Report a problem or idea

Open an issue at [github.com/damianeickhoff/Arca/issues](https://github.com/damianeickhoff/Arca/issues). You need a free GitHub account.

In Arca, Settings → **Help** has the same link under **Report a problem or idea**.

### What helps

- What you did, what you expected, and what happened instead.
- Which version you run (Settings shows it, for example "Arca 1.3.0") and how you installed it (Docker, Compose, Unraid).
- A screenshot, if it shows the problem. Turn on [privacy mode](/Arca/settings/security/#privacy-mode) first if you'd rather not share your amounts.

:::danger[Keep private things private]
Issues are public. Never post your bank's CSV files, account numbers, Enable Banking keys or API keys.
:::

## Before you ask

- Check [Questions and fixes](/Arca/help/faq/).
- Look through the [existing issues](https://github.com/damianeickhoff/Arca/issues?q=is%3Aissue): someone may have asked already.
- See what's coming on the [roadmap](/Arca/roadmap/).
